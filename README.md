# hide-markup

![](https://raw.githubusercontent.com/basyura/inkdrop-hide-marks/refs/heads/main/images/img01.png)

The saved Markdown remains unchanged; only its appearance in the editor is modified.

Press `Enter` within a region with hidden Markdown markers to temporarily reveal them without inserting a newline.

The markers are hidden again when the cursor moves outside the region, including its markers.

Works with both the standard editor and Vim.

## Supported syntax

* `**strong**`
* `~~delete~~`
* `[Inkdrop](https://www.inkdrop.app)` → [link-compact](https://my.inkdrop.app/plugins/link-compact)

## Planned syntax support

* `inline code`
* `> blockquote`

## Requirements

- Inkdrop 6
