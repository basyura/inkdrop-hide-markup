## 目的と非表示の対象

Markdown の強調構文 `**strong**` の開始・終了記号 `**` と、削除構文 `~~delete~~` の開始・終了記号 `~~` をエディタ上で非表示にする。表示状態の変更やカーソル位置の補正では、保存する Markdown 本文を書き換えない。

`@lezer/markdown` が `StrongEmphasis` と解析し、開始・終了記号がともに `**` である範囲を対象とする。複数の強調と入れ子の強調も対象とし、本文の編集後は構文を再判定する。

削除構文は `@lezer/markdown` の `Strikethrough` 拡張を有効にして解析し、`Strikethrough` と解析され、開始・終了記号がともに `~~` である範囲を対象とする。複数の削除構文、強調との混在・入れ子も対象とし、本文の編集後は構文を再判定する。

次の記述は対象外とする。

- インラインコードとコードブロック内の `**`・`~~`。
- エスケープされ、強調・削除構文として成立しない記号。
- 終了記号がないなど、強調・削除構文として成立しない記述。
- `__strong__` の強調。
- 単一チルダの `~delete~`。
- リンクなど、強調・削除以外の Markdown 記号。

`***ab***` では強調を構成する `**` のみを非表示にし、残る `*` はこのプラグインでは隠さない。

以下のカーソル移動・Vim 操作・一時表示・選択と編集の仕様は、強調構文と削除構文の双方に適用する。説明と例で「強調」・`**` と記載している箇所は、削除構文では「削除」・`~~` と読み替える。両構文が混在する入れ子でも、Enter はカーソルを含む未表示の最小範囲を表示し、その範囲に含まれる両構文の記号を表示する。

## カーソル表記

以下の `|` は挿入カーソル位置を表す。例では、非表示の記号も保存される Markdown として記載する。Vim 通常モードのブロックカーソルは、位置の表記ではなく「文字上」と記載する。

## 通常エディタと Vim 挿入モード

非表示の記号をカーソルの独立した停止位置として扱わない。空の選択範囲のカーソルでは、見た目の左端を開始記号の手前、右端を終了記号の直後へ統一する。クリックなどで本文と記号の境界が指定された場合も補正する。

### 左端

| 操作                         | 結果                  |
| ---------------------------- | --------------------- |
| 見た目の左端へ移動・クリック | `\|**あいうえお**`    |
| 左端で `X` を入力            | `X\|**あいうえお**`   |
| `前 \|**あいうえお**` で `←` | `前\| **あいうえお**` |
| `\|**あいうえお**` で `→`    | `**あ\|いうえお**`    |
| `**あ\|いうえお**` で `←`    | `\|**あいうえお**`    |

左端では `←` を押す前から入力が強調の外側に入る。左端から前の文字へ移動するために、左矢印を二回押す必要はない。文書先頭ではそれ以上左へ移動しない。

### 右端

| 操作                         | 結果                  |
| ---------------------------- | --------------------- |
| `**あいうえ\|お**` で `→`    | `**あいうえお**\|`    |
| 見た目の右端をクリック       | `**あいうえお**\|`    |
| 右端で `X` を入力            | `**あいうえお**X\|`   |
| `**あいうえお**\| 後` で `→` | `**あいうえお** \|後` |
| `**あいうえお**\|` で `←`    | `**あいうえ\|お**`    |

右端から次の文字へ移動するために、右矢印を二回押す必要はない。文書末尾ではそれ以上右へ移動しない。

両端での連続入力は強調の外側に保持する。本文途中の入力は本文内に入る。文字単位の補正には文字クラスタ境界を使い、結合した絵文字も一つの移動単位として扱う。

## Vim 通常モード

非表示の記号上にブロックカーソルを停止させない。行末が終了記号の場合は、見えている最後の本文文字上に停止する。

`h`・`l`・左右矢印の通常移動では非表示の記号を飛び越える。`3l`・`2h` などの回数指定も、非表示の記号を文字数に含めない。`0`・`$` による行頭・行末への移動先も補正する。

非表示の強調記号を飛び越える場合だけ、回数指定を考慮した移動先を予約する。予約した移動先は Vim 本体が計算した未補正の位置に対して適用し、ほかのプラグインがリンクなどを飛び越えるために変更した移動先は上書きしない。その位置が非表示の強調記号に入る場合は、通常の記号位置補正を適用する。

### 挿入への切り替え

| 操作                                   | 非表示時の挿入位置             | `X` 入力後の例 |
| -------------------------------------- | ------------------------------ | -------------- |
| `**ab**` の `a` 上で `i`               | 開始記号の手前                 | `X**ab**`      |
| 行の最初の非空白位置が `**` の行で `I` | 先頭の空白の後、開始記号の手前 | `  X**ab**`    |
| `**ab**` の `b` 上で `a`               | 終了記号の直後                 | `**ab**X`      |
| `**ab**` の `a` 上で `a`               | `a` の直後、本文内             | `**aXb**`      |

本文途中の `i` はその本文位置から挿入する。行の最初の非空白位置が強調開始記号でない場合、`I` の通常の移動先を維持する。両端からの挿入は連続入力でも外側を維持する。

これらのキーの特例は Vim 通常モードで適用する。Visual モード、演算子の入力途中、リテラル入力待ちの操作には、この特例を適用しない。

## Enter による記号の一時表示

通常エディタと Vim の両方で、非表示の強調本文内で `Enter` を押すと、その強調の開始・終了記号を一時的に表示する。

- 記号表示のための最初の `Enter` は改行しない。既定動作と後続ハンドラへのイベント伝播も抑止する。
- 通常エディタと Vim 挿入モードでは、開始記号の手前として扱う見た目の左端も表示操作の対象とする。
- 終了記号の直後として扱う見た目の右端は強調範囲外であり、表示操作の対象外とする。
- 記号表示中は記号上へカーソルを移動できる。開始記号の先頭・終了記号の各文字上でも表示を維持する。
- 表示中の範囲内で再び `Enter` を押すと、通常のエディタまたは Vim の処理に戻る。通常エディタでは改行する。
- 表示中の記号に対しては、左右移動と `i`・`I`・`a` の非表示時の特例を適用しない。
- カーソルが強調範囲の外へ移動すると、再び記号を非表示にする。表示維持範囲は開始記号の先頭を含み、終了記号の直後を含まない。
- 表示中に編集した場合は、その編集に合わせて表示維持範囲を移動する。

入れ子の場合は、カーソルを含む未表示の強調のうち最も小さい範囲を表示する。表示する範囲内に含まれる強調記号も表示対象になる。すでに表示中の範囲内なら、次の `Enter` は通常の処理に戻る。

表示専用の操作は、修飾キーなし、IME 変換中でない、単一の空の選択範囲の場合に適用する。Vim の演算子入力中・リテラル入力待ちでは適用しない。複数カーソルの場合、表示済みの範囲は少なくとも一つの選択範囲の移動側端点が範囲内にある間、表示を維持する。

## 選択範囲と編集

カーソル移動・編集のトランザクションで、非表示の記号に入る位置を補正する。範囲選択では、開始側・終了側の位置を補正しつつ選択の方向、複数の選択範囲、主選択の指定を保持する。

単一カーソル向けの左右キー・Vim 挿入切り替えの特例は、複数カーソルや文字列を選択した状態では適用しない。選択・コピーが常に非表示の記号を除外するという仕様ではない。

Vim の文字単位の Visual モードでは、非表示の記号を飛び越えて選択し、本文全体が選択された強調・削除構文には開始・終了記号も含める。本文の部分選択には記号を追加しない。選択の方向と、選択を広げたり縮めたりする際の Vim 内部カーソル位置を保持する。`y` で Markdown をコピーして `p` で貼り付けられる。`d`・`x` も選択した記号を含めて削除し、`p` で貼り付けられる。`c` で記号を含む選択を変更するときは、削除範囲の先頭から入力する。行・矩形選択、マウス操作、IME 変換中、一時表示中の記号はこの補正の対象外とする。

Visual モードの `h`・`l`・左右矢印は、回数指定でも非表示の記号を文字数に含めずに移動する。記号を含む選択でもブロックカーソルは移動先の表示文字に重ねる。他のプラグインが補正した移動先は上書きしない。

編集で強調構文が成立した場合は非表示対象に追加し、成立しなくなった場合は対象から除外する。

## モジュール形式

- `package.json` の `type` は `module` とし、エントリは `./lib/hide-markup.js` とする。
- ソースとテストは `import` / `export` を使い、相対インポートには `.js` を付ける。
- エントリは `activate` と `deactivate` を名前付きで公開する。
- Inkdrop の読み込み時の変換に備え、各ソースの先頭に `"use babel"` を指定する。

## 有効化・無効化

- 有効化時にエディタのロードを待ち、Inkdrop の `editor:add-extension` で拡張を登録する。
- ノート切り替えによるエディタ再生成後も拡張を適用する。
- 無効化時は `editor:remove-extension` で拡張を解除し、記号を通常の表示に戻す。
- 無効化後の遅延ロード通知と、再有効化前の古いロード通知で拡張を登録しない。
- 同じ有効化に対するロード通知で拡張を重複登録しない。
