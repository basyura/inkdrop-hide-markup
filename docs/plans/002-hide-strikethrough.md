# 削除記法の非表示対応

## 目的

`~~AAA~~` の削除記法を、`**AAA**` の強調記法と同様に扱い、開始・終了の `~~` をエディタ上で非表示にする。単一チルダの `~AAA~` は対象外とする。保存する本文は変更しない。

## 修正案

- `docs/specs/001-hide-markup.md` の既存仕様を基準に、削除記法を非表示対象に追加する。
- `lib/markers.js` の構文解析を拡張し、開始・終了がともに二重チルダの削除記法を検出する。
- 強調記法と同じカーソル移動・選択・編集・Vim 操作・Enter による一時表示を適用する。
- インラインコード・コードブロック・エスケープ・未成立の記法は非表示にしない。
- 既存の強調記法の挙動を維持し、削除記法と強調記法の混在・入れ子も確認する。

## 検証

- 二重チルダの構文判定、単一チルダの除外、その他の除外対象、編集による再判定のテストを追加する。
- 通常エディタと Vim の移動・挿入・Enter による一時表示を検証するテストを追加する。
- `npm test` を実行し、既存テストと追加テストの成功を確認する。
- 実装・テスト・関連仕様の整合性を確認する。
