# Vim の Visual モードでのコピー範囲修正

## 目的

Vim の文字単位の Visual モードで強調 `**` と削除 `~~` を選択した際、見た目の選択範囲に対応する Markdown を正しくコピーできるようにする。

## 修正案

- link-compact の参照コミットを基準に、非表示の記号を飛び越える Visual モードの移動と、Vim 内部のカーソル位置を同期する方法を調査する。
- 強調・削除の本文全体を選択した場合に開始・終了記号を含め、部分選択では不要な記号を含めないよう、選択方向と移動先を保持して選択範囲を補正する。入れ子や隣接する構文も確認する。
- 一時表示中の記号、行選択・矩形選択、通常の範囲選択や複数選択への影響を確認する。選択範囲の変更に伴う削除・変更操作も検証する。
- 実際の Vim ライブラリを使う回帰テストを追加し、前方・後方選択、選択の拡大・縮小、yank と貼り付けを検証する。
- 変更後の挙動を `docs/specs/001-hide-markup.md` に反映し、実装とテストが仕様に整合することを確認する。
- `npm test` を実行する。
